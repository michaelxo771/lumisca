# Lumisca Shopify Theme

## Setup Instructions

### 1. Connect To Shopify
- Go to your Shopify admin
- Navigate to Online Store > Themes
- Click "Add theme" > "Upload zip file"
- Or use Shopify CLI: `shopify theme push`

### 2. Add Your Pixel IDs
In Shopify admin go to Online Store > Themes > Customize > Theme Settings > Pixels & Analytics:
- Meta Pixel ID: Your Facebook Pixel ID
- TikTok Pixel ID: Your TikTok Pixel ID
- GA4 Measurement ID: Your GA4 ID (format: G-XXXXXXXXXX)
- GTM Container ID: Your GTM ID (format: GTM-XXXXXXX)
- Microsoft Clarity ID: Your Clarity Project ID
- Klaviyo Public API Key: Your Klaviyo public key

### 3. Add Your Products In Shopify Admin
Create these 4 products:
- Lumisca Pro Red Light Hair Growth Cap — Handle: lumisca-pro-hair-growth-cap — Price: £64.99 — Compare at: £129.99
- Lumisca Glow Red Light Face Mask — Handle: lumisca-glow-face-mask — Price: £54.99 — Compare at: £109.99
- Lumisca Rest Heated Eye Mask — Handle: lumisca-rest-eye-mask — Price: £29.99 — Compare at: £59.99
- Lumisca Complete Bundle — Handle: lumisca-complete-bundle — Price: £124.99 — Compare at: £299.97

### 4. Configure Theme Settings
In Shopify Customize panel:
- Add social media URLs (TikTok, Instagram)
- Add WhatsApp number (with country code)
- Set announcement bar messages
- Enable/disable popups
- Add Klaviyo API key

### 5. Add Product Images
Upload high quality product images to each product in Shopify admin.

### 6. Connect Domain
In Shopify admin go to Settings > Domains and connect lumisca.co.uk

### 7. Pre-Launch Checklist
- [ ] All 4 products created with correct prices and handles
- [ ] Product images uploaded
- [ ] Meta Pixel ID added
- [ ] TikTok Pixel ID added
- [ ] GA4 connected
- [ ] Klaviyo API key added
- [ ] Domain connected
- [ ] Payment methods configured (Klarna, Clearpay)
- [ ] Shipping zones set to UK only
- [ ] Test order placed
- [ ] VAT configured if registered
